# 9Like Static Site (GitHub Pages)

This branch contains a simple static landing page for the 9Like project. It is intended to be published via GitHub Pages from the `gh-pages` branch.

Publish steps:
1. Go to your repository Settings → Pages.
2. Under "Source", choose the `gh-pages` branch (root) and save.
3. After a minute, your site should be available at:

   https://sakiratomotoyosi2345-crypto.github.io/9like/

Notes:
- This site is a demo/static frontend only. Do NOT use localStorage for production user data or authentication.
- If you want, I can add a simple GitHub Actions workflow to automatically build/deploy or add a server scaffold.
